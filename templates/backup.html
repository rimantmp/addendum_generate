Pulihkan Database dari File

Unggah file cadangan .db sebelumnya untuk mengembalikan seluruh isi data.

Perhatian: Memulihkan database akan menggantikan data yang sedang aktif dengan data dari file cadangan. Sistem akan otomatis membuat salinan darurat data lama sebelum proses pemulihan.

💡 Rekomendasi Pemeliharaan

  • Lakukan pencadangan (unduh .db) secara berkala, terutama setelah memasukkan alokasi SK Realokasi baru.
  • File cadangan dapat disimpan di flashdisk, Google Drive, atau penyimpanan awan kantor yang aman.
  • Sebelum memulihkan data lama, pastikan tidak ada staf yang sedang mengedit data pada waktu bersamaan.
